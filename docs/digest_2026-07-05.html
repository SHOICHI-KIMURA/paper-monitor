Deep learning classification of nasal anatomical variants on computed tomography for endoscopic sinus surgery.

要約保存 Scientific reports / IF 3.8 / 2026-07-01
3行要約
  • 内視鏡下鼻副鼻腔手術（ESS）の安全性向上のため、冠状断CT画像から遊離前篩骨動脈（FFAEA）、Onodi細胞、Haller細胞を自動検出するAIモデルを開発した。
  • CNNモデルはFFAEAで77.8%、Onodi細胞で74.6%のバランス正確度を達成し、ビジョン言語モデル（BioMedCLIP）はHaller細胞の検出（73.5%）でCNNを上回った。
  • 標準化されたCT画像を用いた副鼻腔の解剖学的変異の自動識別における概念実証（proof-of-concept）が示された。
なぜENTで重要か
  • ESSにおける重篤な合併症（視力障害や頭蓋内損傷）を回避するために極めて重要な解剖学的変異の認識をAIが支援できる可能性を示している。
  • 画像診断におけるダブルチェックや、若手医師の教育・手術計画の策定を支援するツールとしての応用が期待される。
  • 最新のビジョン言語モデル（BioMedCLIP）が、特定の解剖学的変異（Haller細胞）の検出において従来のCNNを凌駕する可能性を示した。
