  • 若年、アジア系、甲状腺癌患者など、これまで見過ごされがちだった高リスクサブグループを特定し、個別化されたスクリーニングと予防戦略の必要性を示唆した。

Effect of Dupilumab on Airway Inflammation in Patients With Persistent Asthma.

必読 Allergy / IF 12.4 / 2026-05-29
3行要約
  • 持続性喘息患者を対象とした第2a相RCTで、デュピルマブが気道粘膜・全身性炎症、遺伝子発現に与える影響を評価。
  • デュピルマブは肺機能と喘息コントロールを改善し、循環T2バイオマーカーを減少（punadj < 0.001）。気道粘膜生検の好酸球数等に変化なしも、BAL/ブラッシングで炎症関連遺伝子セットのダウンレギュレーション、生検で杯細胞数（punadj = 0.0336）と粘液面積（punadj = 0.0426）の減少を認めた。
  • デュピルマブによる肺機能改善の細胞・分子レベルでのメカニズム解明に寄与するデータを提供。
ENTでの読みどころ
  • 鼻科（慢性副鼻腔炎）、アレルギー科（アレルギー性鼻炎、喘息）、気道疾患（気管支喘息との合併）
  • デュピルマブの薬物療法における作用機序理解、特に気道粘膜における炎症細胞数ではなく遺伝子発現や杯細胞・粘液産生への影響を患者説明や治療選択に活かせる。慢性副鼻腔炎におけるT2炎症研究の設計にも示唆。
  • デュピルマブが鼻茸を伴う慢性副鼻腔炎（CRSwNP）にも適応があるため、その作用機序を深く理解することは、CRSwNP患者の病態理解や治療効果の予測、さらには他のT2炎症性疾患への応用を考える上で重要。
限界・注意点
  • 第2a相試験であり、対象患者数が少ない（n=20 vs 22）。観察期間が12週間と比較的短く、長期的な影響は不明。気道粘膜生検での炎症細胞数に有意な変化がなかった点は、解釈に注意が必要。
  • 喘息患者でのデータであり、鼻茸を伴う慢性副鼻腔炎（CRSwNP）など他のENT領域のT2炎症性疾患に直接外挿する際には、さらなる研究が必要。遺伝子発現の変化が臨床的アウトカムにどの程度寄与するかは、より大規模な研究で確認が必要。

必読 JAMA otolaryngology-- head & neck surgery / IF 8.5 / 2026-05-28
3行要約
  • オーストラリアの認知機能正常高齢者312名を対象とした3年間の前向きコホート研究で、末梢聴力、語音弁別能、補聴器使用が皮質萎縮と認知機能にどう関連するかを検討。
  • 3年間で、ベースラインの語音弁別能の低さが、末梢聴力や補聴器使用とは独立して、下頭頂葉、楔前部、中側頭皮質、上側頭溝の皮質菲薄化加速と関連した。
  • 末梢聴力ではなく、語音弁別能（中枢性聴覚処理能力）が脳の構造的変化と関連する可能性を示唆し、早期の神経脆弱性マーカーとなりうる。
ENTでの読みどころ
  • 聴覚、特に中枢性聴覚処理障害と認知機能低下の関連。高齢者の難聴診療、補聴器適応、患者説明。
  • 難聴患者への認知症リスク説明において、純音聴力だけでなく語音弁別能の重要性を強調できる。中枢性聴覚処理能力を改善する介入（補聴器調整、聴覚リハビリ）の意義を再評価する視点。
  • 難聴と認知症の関連メカニズム解明に一石を投じる。語音弁別能検査の臨床的価値を再認識させ、今後の研究で中枢性聴覚処理能力をターゲットとした介入効果検証の必要性を示唆する。
限界・注意点
  • 3年という追跡期間は脳構造変化を見るには比較的短く、認知機能低下との直接的な関連は示されていない。対象は認知機能正常高齢者であり、より進行した認知症患者への外挿は慎重に。
  • 語音弁別能の具体的な評価方法（使用言語、ノイズの種類、S/N比など）の詳細が不明。皮質菲薄化が認知機能低下に直結するかの長期的な検証が必要。

The elongated ciliated cells derived from nasal polyps are distinctly different from ciliated cells in different parts of the nasal mucosa.

必読 Rhinology / IF 4.8 / 2026-05-28
3行要約
  • CRSwNP患者32名と非CRSwNP患者22名の鼻生検組織を用い、鼻副鼻腔全体の線毛細胞を系統的に解析し、CRSwNPの病態における線毛異常の部位特異性や細胞集団の特定を検討した。
  • CRSwNP患者では線毛長が有意に長く（8.17 ± 3.35 μm vs. 5.67 ± 1.64 μm）、鼻茸組織中に異常に伸長した線毛細胞（ECCs）が8.10% ± 3.56%存在し、外側線毛は最大20.0 μmに達した。
  • 鼻茸に特異的な異常伸長線毛細胞集団の存在を明らかにし、これがCRSwNPの発症・進行における重要な病原性因子である可能性を示唆した。
ENTでの読みどころ
  • 鼻科領域、特に慢性副鼻腔炎（CRSwNP）の病態生理。
  • CRSwNPの難治性や再発性の背景にある病態理解を深める。将来的な新規治療標的の探索や、病態に基づいた患者説明に役立つ可能性。研究設計においては、線毛機能異常を評価する際の細胞レベルでの着眼点を提供する。
  • CRSwNPの病態解明に直結する基礎研究であり、線毛機能異常がCRSwNPの主要な病態であるという認識を深める。特に、鼻茸に特異的な異常線毛細胞の存在は、CRSwNPのサブタイプ分類や治療反応性の予測因子となる可能性があり、今後の研究で注目すべき視点となる。
限界・注意点
  • 抄録からは、ECCsの機能障害の具体的なメカニズムや、CRSwNPの重症度や治療反応性との関連については不明。また、in vitroでのALI培養での再現性はあるものの、in vivoでの病態進行における役割の詳細はさらなる研究が必要。
  • 本研究は病態生理の解明が主目的であり、現時点での直接的な臨床応用には至らない。ECCsがCRSwNPの診断マーカーや治療標的となりうるか、その特異性や感度については今後の検証が必要。
